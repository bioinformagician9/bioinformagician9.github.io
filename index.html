step 1 · cluster

Every tutorial is a cell. Here is the atlas.

The channel's videos, clustered by topic like a single-cell UMAP. Bigger cells have more viewers. Type a tool into FeaturePlot to light up every video that uses it, or tap a cluster to run FindMarkers.

step 2 · order cells in pseudotime

The journey, run as a pipeline.

Ordered by upload date, the tutorials form a trajectory. Each branch point is an era of the channel. Open one and the pipeline runs a full turn on it: sample, alignment to topics, differential expression against the rest of the channel, library growth and the lead transcript.

Khushbu wears two hats. By day, she finds gene and protein targets in omics and NGS data, and builds the pipelines that make it work at scale. As an educator, she opens up the same toolkit on the channel, with tutorial code on GitHub so you can rerun the analysis yourself. The aim is a community where bioinformaticians connect, learn and share ideas.
